# Codex Pet

This context defines the language for the selectable pet appearances and the way they express Codex activity.

## Pet presentation

**Pet appearance**:
A selectable illustrated character that represents Codex activity in the Termux overlay. Every appearance communicates the same activity states.

**Animation playback**:
The ordered poses and cadence a pet appearance uses to express an activity state. A sequence may repeat or settle into a final pose.
