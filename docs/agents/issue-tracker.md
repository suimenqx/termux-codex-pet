# Issue tracker

Use GitHub Issues in `suimenqx/termux-codex-pet` through authenticated `gh`.

- Parent specification: #1. Implementation tickets: #2–#15.
- Triage label: `ready-for-agent`. Use native issue blocking relationships.
- Fetch the full issue and comments before implementation/review.
- Work directly on main; validate, commit and push. No topic branches or PRs.
- Do not close the parent specification as a side effect of a stage. Required device checks must pass before a ticket is complete.
