# 秋田犬当前奔跑基线

当前 Running 是 20 帧、834ms 的透明 PNG 循环，物理帧 `00`–`19` 按 v2
源视频顺序播放，曝光按 `42、42、41ms` 重复。来源、哈希和已知限制见
[`docs/artwork/akita/2026-10-grok-v2/brief.md`](artwork/akita/2026-10-grok-v2/brief.md)
及其 `delivery.json`。

## 当前可验证的内容

- 帧尺寸为 256×256，显示视图为 64dp。
- 头部位置在整圈内保持稳定，保留部分身体上下起伏。
- 第 15、16 帧的自然眨眼保留；毛发纹理的轻微帧间闪动是已知生成特征。
- `current-running.json` 保存每帧可见脚掌采样点；这些点用于显示审计，不是关节中心、接触力或步态认证。
- `tools/audit_animation.py` 检查帧序、曝光、循环接缝和相对髋部轨迹；自动通过不等于自然步态或美术验收通过。

## 人工复核重点

原速播放时查看完整循环、末帧到首帧、四只脚的身份、躯干起伏、尾巴跟随和
纹理闪烁。慢放和逐帧只用于定位问题，不能替代原速判断。Running→Ready
的同宠物入口是 ready/05、06、07，各 120ms，再进入一次轻跃和休息循环；
任意 Running 相位都应能立即被新状态打断。

## 后续修改约束

如果更换 Running 素材，必须同时更新 v2 制作单、`current-running.json`、
`pet.json` 的 revision/帧表，并重新检查 256×256、透明边缘、曝光、循环接缝、
Ready 入口和设备原速观感。不能只增加帧数、统一缩短时长或按透明外接框逐帧
缩放来声称动作改善。

犬类研究只能帮助理解可能的支撑、腾空和回收关系，不能把研究中的犬只姿势
直接当作本角色的固定坐标。当前生产图仍以角色身份、体量和可读性为第一优先级。
