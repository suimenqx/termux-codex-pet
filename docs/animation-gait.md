# 秋田犬四足奔跑与验证

当前 **rig-v1 使用 32 个姿势 × 20ms = 640ms**，与 Idle、Needs input、Ready、Blocked 共用一个分层模型。尺度和制作流程见[骨骼制作规范](animation-rig.md)，曝光表以 `codex_pet/animation.py` 为准。

## 接触相位

这是一套面向小尺寸秋田角色的简化、不对称疾驰设计；相位属于本模型的动作设定，不是所有犬只通用的生物力学常量。朝向、近远侧及接触身份在整个周期保持一致。

| 脚掌 | 开始触地相位 | 支撑占周期比例 | 支撑时间 | 投影倍率 |
| --- | ---: | ---: | ---: | ---: |
| 远后脚 `hind_far` | 0.00 | 0.28 | 179.2ms | 0.9 |
| 近后脚 `hind_near` | 0.10 | 0.28 | 179.2ms | 1.0 |
| 远前脚 `fore_far` | 0.44 | 0.32 | 204.8ms | 0.9 |
| 近前脚 `fore_near` | 0.56 | 0.32 | 204.8ms | 1.0 |

依次为后肢支撑与驱动、短暂腾空、前肢先后接触与支撑、回收腾空。周期相位 0.38–0.44、0.88–1.00 没有支撑脚。每只脚都有自己的摆动轨迹与接触标记，不复制另一只脚的同相运动；遮挡由图层关系决定。

头和身体使用小幅刚性起伏与俯仰，骨骼长度保持不变。躯干保留紧凑造型，没有模拟真实犬的脊柱伸缩；这项风格选择与尺度一致性分别记录，不能把它描述成完整的动物运动仿真。

## 支撑速度与回收

原地跑的画布不移动。支撑期间脚掌相对画布向后扫；若角色根在虚拟世界向前运动，两者应抵消。所有脚掌由一个地面速度推导：

```text
步幅 = 地面速度 × 周期 × 支撑相位长度 × 固定透视倍率
支撑脚 x 速度 / 透视倍率 = -地面速度
```

当前地面速度为 **240 设计单位/秒**，周期 0.64 秒。选择这个速度是本角色的动作设定，并受到 IK 可达范围约束：制作时对 4000 个相位采样，240 时最紧的近后腿仍有约 0.506 单位的伸展余量；250 会出现约 0.167 单位超伸，已拒绝。支撑步幅不再逐条腿各自猜数。

回收的水平轨迹使用三次 Hermite 曲线，两端速度与支撑阶段一致；抬脚高度为 `lift × sin²(πu)`，落地/起跳瞬间垂直速度为零。脚掌旋转也在两端缓入/缓出。`u` 是回收段内 0–1 的时间位置。前后脚抬高量、身躯起伏与摆尾幅度属于模型动作设计，记录于源码与 `model.json`。

改变步幅、脚掌角度或身体起伏后，必须检查连续轨迹。只在 32 个导出时刻合法仍可能在两个时刻之间超出 IK 可达范围。

## 审查四条腿

```sh
python tools/audit_animation.py --state running --cycles 2 --density 3
python tools/preview_animation.py --state running --cycles 2
```

审计先验证当前模型、制作源码、PNG、运行 RGBA 与曝光时序，然后读取导出的关节及遮挡。报告含四条脚掌轨迹、接触帧、骨长误差、地面高度误差和固定尺度。联系表仍用洋红/青色标后脚，绿色/橙色标前脚；被另一条腿盖住的脚不冒用可见脚的位置。

同时查看完整跑步循环的末两帧与首两帧。`tests/test_akita_rig.py` 检查循环位置/速度连续、接触边界连续、共同支撑速度和固定骨长；`tests/test_art.py` 检查真实 PNG 边界、完整编号与回退；审计的 PASS 不代表已经由人确认原生显示的自然程度。

设备端采用有截止时间的单调时钟，过期帧跳过，避免阻塞后快速补播。20ms 是目标曝光时长；首次解压、原生缓冲区复制、显示刷新和系统负载都会影响实际呈现，不能仅凭 32 张图片宣称稳定 50fps。重复播放从缓存取预乘像素，复用同一个原生位图，避免逐帧传输和解码 PNG。

## 历史素材

旧版独立绘制的 8 帧跑姿有过前后腿相位、头身尺寸和格子配准问题。源表 `docs/artwork/running-gait-sheet.png` 与 `tools/prepare_running_frames.py` 仅保留为历史复现工具，包含当时下排 10px 配准和 1.18 倍居中补偿。它们不参与 rig-v1 的绑定、导出或播放，不能覆盖新的生产目录。

如需检查历史结果，只导出到隔离目录：

```sh
python tools/prepare_running_frames.py docs/artwork/running-gait-sheet.png \
  "$HOME/.cache/codex-pet/artwork-review/legacy-running"
```

此前彩色毛边来自把直通道 RGBA 原样写入 Android 预乘共享位图。旧版本改用 Android PNG 解码修复了透明契约；本次 20ms 连续播放暴露逐帧 PNG 路径的连接不稳定，因此将预乘放到离线导出，再从像素包读取、缓存并复用一个原生位图。首次显示不再执行逐像素转换。`tests/test_frame_display.py` 穷举通道/alpha 值验证预乘舍入，检查真实半透明毛边、顺序应答和断连资源释放。历史版本的设备确认不代表用户已经确认当前新素材的动态效果。
