# Agent 生成与补帧流程

入口是[图片与尺寸规范](animation-assets.md)。本流程使用[制作单](templates/pet-animation-brief.md)传递上下文；动作阶段和时间填写方法见[动作规范](animation-motion.md)。提示词控制制作意图，文件测量、视觉审查和真实播放负责判断结果。

| 工作范围 | 执行范围 |
| --- | --- |
| 只改既有图片的时长 | 记录图片版本，执行步骤 1、3、6；模型/生成/导出项注明图片未变并引用既有证据。时长调整不证明旧图已符合全部新规范。 |
| 修图或补帧 | 复用有效的模型和布局参照，执行涉及的阶段；缺少当前视角的尺寸基准时先补齐。重新审查受影响动作段、循环及状态切换。 |
| 新角色、新视角或重定角色尺度 | 完成全部阶段；共用模型或构图变动影响的所有状态一并审查。 |

## 1. 确认目标与生产约束

读取外观注册、图像加载、动画表以及相关测试，记录当前提交。分清本次是修单帧、补中间帧、替换动作、重绘角色还是新增外观；列出受影响状态、保持的角色版本和允许改变的内容。

复制制作单到本次素材目录，填写输出契约、状态语义、参考图的角色、动作周期/保持规则和交付范围。修复或补帧默认沿用已确认角色与步频；需改变时明确记录原因。没有外观设计信息的新宠物，先完成身份主图与角色设定，再批量画动作。

**完成条件：** 输入和边界明确，所有必要字段有值或有理由的“不适用”；涉及数值的条目能追溯到源码、模型、公式或测量。缺少尺寸模型时进入下一步建立它，不临时猜一个放大系数。

## 2. 建立角色参照包

按尺寸规范建立身份主图、所需中性视图、共同尺度/构图标注与动作极值对照。可以借用已验证参照包，但必须核对版本、文件内容和适用视角。复用旧素材的画风不代表旧素材自动通过新规范。

图像输入分别标明身份、尺度、姿势和布局用途。标注图与干净绘画分开保存，防止坐标线、标签或格线出现在最终图片里。先确认全部状态能容纳于共同构图，再锁定该角色版本。

**完成条件：** 同视角结构测量可重复；多视图尺度关系和动作极值对照已审查；构图原点、支撑基准、标记坐标系、配色/配件规则都有记录。这里的“确认”是制作验收记录，不额外引入每一步都向用户请示的流程；已有用户约束继续有效。

## 3. 先做关键姿势和时间表

为每个状态填写进入、循环、结束/保持规则；列出关键事件的时刻、四肢支撑和遮挡关系。生成或绘制关键姿势草稿，逐帧翻看并组成原速粗预览。先解决模型比例、受力、轨迹和首尾连接，再细化毛发与阴影。

**完成条件：** 动作意图在运行显示大小下可读，关键事件时间明确，极值未越界，首尾能衔接；原速粗预览没有靠美化掩盖的动作错误。每张关键图都有稳定 `pose_id`，不是仅靠临时文件编号识别。

## 4. 按动作段生成中间帧

每次提供固定模型参照、对应视角的尺度/布局图，以及当前段的前后关键姿势。补帧输入包括时刻、时间比例、计划轨迹、支撑变化和遮挡；“介于 A 与 B 之间”不足以描述关节怎么走。循环最后一段同样以末姿势和下一周期首姿势为两端。

先检查相邻一段的尺度与轨迹是否正确，再扩展到剩余动作。单段失败时记录具体差异，例如“近侧前脚在触地前倒退”“补帧鼻口比例变大”，修正输入控制或重画相关段。重复得到同一缺陷时改变生成方式：补控制草图、做局部编辑、分开生成，或采用已授权的离线分层/骨架制作后导出 PNG。生成失败不通过降低验收要求解决。

**完成条件：** 每个中间帧对应明确时间点；固定身份没有被新稿逐步替换；全部动作段和循环接缝通过[模型与动作审查](animation-acceptance.md#模型与动作审查)。调整曝光后重新核对周期与关键事件时刻。

## 5. 导出到候选目录

生成工具返回的源文件保留原样。记录实际尺寸、是否真实透明、网格布局与图片哈希。先在 `~/.cache/codex-pet/artwork-review/<task-id>/` 导出候选；通过检查的源图和制作记录随后放入 `docs/artwork/<pet>/<revision>/`。目录名用于追溯，不改变运行时素材查找方式。

对已满足等格布局的动作表，使用现有导出器。下面是一个八姿势表的命令示例，实际网格和帧数取自制作单：

```sh
artwork_stage="$HOME/.cache/codex-pet/artwork-review/example-running"
mkdir -p "$artwork_stage"
python tools/prepare_sprite_frames.py source-sheet.png "$artwork_stage/frames" \
  --columns 4 --rows 2 --frame-count 8
```

一张独立正方形源图可按 `--columns 1 --rows 1 --frame-count 1` 导出到自己的临时子目录，再按姿势映射命名。导出器每次从 `00.png` 开始写入，不要把多张单帧源图连续导出到同一目录而覆盖前一帧。使用新的空输出目录；它不会自动清除上次导出的多余 PNG。

源图网格不成立时先修布局或拆成单帧，不靠为每个姿势增加独立 zoom/offset 参数来制造一致性。通用导出器不修复断肢、格线或角色尺度错误。

导出的候选可以用 `preview_animation.py --candidate` 按显式文件/曝光清单播放；清单格式和命令见[候选验收](animation-acceptance.md#现有工具能证明什么)。不必为了预览先覆盖生产帧，候选清单也不会改变运行时播放表。

**完成条件：** 候选通过文件检查；裁切和降采样后仍保持模型、细线与动作可读性；每张 PNG 都能追溯到源图、格号/姿势和导出命令。源分辨率/颜色解释发生变化时，不能直接复用旧的视觉通过记录。

## 6. 验收、接入并交付

按[验收与接入](animation-acceptance.md)检查全部逻辑播放位置、跨状态切换、回退图和数量徽标。通过候选审查后，才进入仓库生产路径做集成验证；遵守 `AGENTS.md` 的 main 分支、测试和设备部署流程。

保存通过版本的模型参照、源图、制作单、逐帧时间映射、完整提示词、参考输入、导出命令与审查证据。记录工具实际返回的模型/任务标识；未提供的元数据写“未提供”。随机 seed 只有工具提供时才记录，同一提示词或 seed 不承诺逐像素复现；确定性复现针对保留下来的源文件和导出步骤。

**完成条件：** 每个验收项有通过、失败或待验证结果及证据；没有待解决的素材缺陷；设备验证缺口明确记录。最终报告区分已实现内容和未验证内容，不能用“已生成”替代“已通过”。

## 可复用提示词

以下模板用于支持参考图输入的图像工具，使用前替换全部花括号字段，并实际附上对应图像。工具不支持的尺寸/透明度/参考数量要求记录为限制；生成后按真实文件检查。文字标注与动作草图可作为输入控制，交付图不绘制这些辅助内容。

### 建立模型视图

```text
任务：为同一宠物 {pet_id}、模型版本 {model_revision} 制作中性姿势 {view_id}。
输入图及用途：{identity_reference} 固定身份和画风；
{layout_reference} 固定画布、镜头尺度和构图基准；{other_view} 说明同一模型的结构。
角色身份：{脸部结构、毛色分区、耳尾、配件、描边、光照和色彩规则}。
固定配件：{主参照、带宽/材质、颜色取样、扣件位置及遮挡}；除明确设计要求外，不按状态改色或增删。
投影与镜头：{projection_and_camera}。源画布目标：{source_canvas}。
依据附图的标注保持 {结构点与模型尺度关系}，构图原点为 {origin_uv}；
中性支撑基线为 {ground_v}。姿态为 {neutral_pose}。
全身和尾耳完整，背景真实透明；输出干净绘画，辅助线和文字仅用作输入参考。
```

建立第一个尺度参照时，布局图是本次明确记录的设计选择；尚未测量的值先在布局阶段确定，不能用空字段继续批量生成。

### 关键姿势或单帧

```text
任务：在已锁定角色 {model_revision} 上绘制动作 {state} 的姿势 {pose_id}。
输入角色/尺度/布局图：{reference_paths_with_roles}；姿势输入：{pose_reference}。
源画布：{source_canvas}；视角和光照：{view_and_light}。
沿用同一相机尺度、构图原点 {origin_uv} 和支撑基线 {ground_v}。
动作阶段与时刻：{phase}，{t_ms} 毫秒，之后曝光 {hold_ms} 毫秒。
头、胸、髋目标与预期形变：{body_landmarks_and_deformation}。
近/远前肢、近/远后肢分别：{每只肢体的接触、关节方向、脚掌目标、可见或遮挡}。
尾巴及配件的跟随关系：{secondary_action}。
保持固定的身份、配色和表面纹理；让肢体按姿势改变，模型尺度保持参照定义。
输出一张完整透明帧，只包含角色与已约定的配件/效果；辅助线和文字仅作输入参考，
所有动作内容位于该画布内。
```

### 补中间帧

```text
任务：补动作段 {segment_id} 在 {t_ms} 毫秒的一个真实中间姿势。
固定身份/尺度/布局参照：{canonical_references}。
前端：{pose_A}，时刻 {t_A}；后端：{pose_B}，时刻 {t_B}。
时间位置：{(t_ms-t_A)/(t_B-t_A)}；这是时间比例，关节遵循下面的路径。
头胸髋路径、运动方向与预期起伏：{body_paths}。
四足接触和遮挡计划：{contact_and_occlusion_plan}。
脚掌与尾巴的弧线/中间控制姿势：{arcs_or_breakdown_reference}。
完整沿用模型身份、镜头与共同构图。画出一个解剖连贯的姿势，
保持每条肢体的身份与合理遮挡，输出单张透明帧。
```

### 局部修复与动作表

局部修复提示词明确 `{失败帧}`、`{失败部位}`、`{实际偏差}`、`{正确模型/前后帧}` 和 `{目标变化}`，其余结构按参照保留；工具支持时用编辑区域限定影响。重导出后复查相邻两段与循环接缝。

批量动作表在单帧模板上追加：`{columns} 列 × {rows} 行，等大的正方形格，按行排列；每格 pose_id 顺序为 {ordered_pose_ids}；每格使用同一归一化布局；全图真实透明，干净无沟槽、格线或文字。` 格子数量以制作单为准。角色跨格或动作身份混乱时拆小批次，不能把网格长宽比检查当作生成成功。
