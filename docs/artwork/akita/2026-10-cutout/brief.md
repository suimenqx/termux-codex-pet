# 秋田犬原图拆层与曲线动画实验

**状态：用户真机否决，已结束本轮实验。** 独立候选 `akita_run_cutout_v1` 已从本机日常宠物目录撤下，原秋田犬保持不变。用户明确授权“用代码离线拆分、变形和组合原秋田犬贴图，控制动作后导出帧”。该授权是在动作参考生成小样失败后给出的，见 ../2026-10-motion-reference/brief.md。

## 模型与制作边界

唯一绘画输入为当前 Running/00，冻结为 source.png；原画的脸、蓝项圈、躯干、卷尾、近前肢和近后肢拆成带透明边缘的贴图。原前腿挡住的腹部，用同图奶油色胸口区域(166,166)–(190,183)补出；这是隐藏面的近似重建，不是原图中已有的完整腹部。远侧肢体复用近侧贴图，按固定透视比例和阴影调整，属于本实验的近似，不能声称原画提供了完整隐藏面。没有重画头脸，没有复用被否决的41e8407角色造型，也没有生成新毛发。

256×256 RGBA8/sRGB，64dp，固定画布；蒙版从实际原图标注，头鼻中心约(212,117)、肩(135,159)、髋(66,159)、近前足底约233、近后足底约224px，手工±3px。这些是本轮创作定位，不是解剖标定。身体的胸髋分别小幅起伏，头脸只做刚性跟随，尾巴在根部轻摆；用原纹理的网格变形连接肘/膝和脚，避免整根腿只绕一个点摆。脚掌支撑段保持近似平放，摆动段屈曲回收。

## 连续动作设计

周期640ms延用现有比较基准，16个40ms采样是离线导出选择，非自然程度保证。选择紧凑同侧领腿的卡通疾驰；相位是待检验设计值，不声称来自犬类实测或直接复刻Pixel Dog。所有脚共用同一虚拟地面后扫速度；摆动用带端点速度的闭合曲线回收，关节用双段解算并保留脚掌方向。

| 脚 | 支撑开始（周期相位） | 支撑结束 | 层级/足底 |
| --- | ---: | ---: | --- |
| 远后 | 0.00 | 0.28 | 身体后方、211px |
| 近后 | 0.12 | 0.40 | 身体前方、224px |
| 远前 | 0.38 | 0.66 | 身体后方、220px |
| 近前 | 0.50 | 0.78 | 身体前方、233px |

0.78至下一圈0.00为收腿腾空；同对脚短暂重叠支撑，后肢与前肢在0.38–0.40接续。支撑脚相对身体由前向后52px/0.28周期，即约0.290px/ms。摆动的水平端点速度接支撑段，足底抬升采用零端点垂直速度的弧线。遮挡来自画面层级，不能据坐标断言脚在最终图中可见。胸在前肢承重时下沉，髋在后肢承重时下沉，二者不同相；幅度、肢长与透视比例均属可调创作参数。

## 验收与发布范围

先检查拆层接缝、旧腿残影、纹理拉伸、纸片感和全循环四脚身份；再看原速并排对照。失败时只调整参数/蒙版，不把脚路径数学连续当作好看。完整静态文件与曲线检查通过后才独立导入测试包，并在手机邀请用户判断。其他状态复用原秋田，原Running→Ready过渡保留，打断视觉是否匹配需要单独检查，不默认为通过。

不会替换 `akita`。最终手工观感状态仍需用户反馈；文件/时序/GUI检查仅证明实现与资源有效。

## 当前交付与复现

导出器 build.py，蒙版与控制点在该文件顶部；关节控制先双段解算，再形成柔和曲线，使原毛发贴图连续弯曲。膝/肘控制点不是最终像素中精确关节位置。所有帧来自同一张 source.png；没有跨帧混合、光流补帧或逐帧重新生成。完整映射和文件指纹见 export.json，逐相位控制记录见 motion.json。

在 Termux 中，离线制作需要 `pkg install python-numpy python-pillow`；本机实测 NumPy 2.4.4、Pillow 12.3.0，NumPy 包同时安装 libopenblas。该依赖不进入安装脚本或运行时导入。

```sh
python docs/artwork/akita/2026-10-cutout/build.py --output "$HOME/.cache/codex-pet/akita-cutout-export"
codex-pet pet import "$HOME/.cache/codex-pet/akita-cutout-export"
codex-pet pet use akita_run_cutout_v1
```

输出目录必须不存在。候选ID已导入时拒绝覆盖；修改实验应先建立新版本ID。恢复秋田犬可用 `codex-pet pet use akita`，恢复其他宠物使用它的ID。导入本身不会切换。

[原速同步对照](review/comparison.html)包含冻结的生产帧和候选帧，支持慢放、时间拖动、背景及显示尺寸切换；[16帧联系表](review/contact-sheet.png)检查整圈。它们不能代替手机64dp实时观看。
