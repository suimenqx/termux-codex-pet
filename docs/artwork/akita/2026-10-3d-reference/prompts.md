# 给 3D 拟合 AI 的任务说明

请把本目录视为一个角色参考包，而不是可以自由改写的素材库。

## 核心任务

根据 `canonical/idle-highres.png` 和 `canonical/running-highres.png` 建立同一只秋田犬的可编辑 3D/骨骼模型。保持现有斜侧朝右镜头中的身份、头身比例、脸部白色区域、蓝色项圈和卷尾；使用 `generated/` 中的正面、纯侧面和背面候选，仅补充不可见的体宽、身长、尾根和背面分区，不得让它们覆盖现有身份参考。

## 建模细节

- 模型为圆润、蓬松、玩偶感的秋田犬幼犬，不是写实成年犬。
- 眼睛使用棕色虹膜、黑色瞳孔和小高光，并保留现有眉点；眼眶线应在 64dp 缩小后仍然干净。
- 嘴部保留友好的张嘴表情、深色口腔和粉色舌头；嘴唇、舌头和鼻子应能独立调整。
- 脸颊、胸口、尾巴和腿部使用不同的毛长/蓬松度；尾巴更蓬，腿保持短而粗。
- 项圈是同一条素蓝色哑光项圈，随颈部旋转和遮挡变化，不改变颜色。
- 预留眼睛闭合、张嘴、舌头、耳朵、尾巴和四肢的动画控制；四脚要能分别处理接触、离地、回收和遮挡。

## 相机与校准

- 先建立正交或弱透视相机，再对齐现有斜侧朝右参考；不要为了贴合某一帧而改变相机。
- 固定脚底地面线、头顶高度、鼻尖位置、髋部位置和尾根位置。
- 用 `canonical/production-idle-00.png`、`canonical/production-running-00.png` 和 `canonical/production-ready-04.png` 做 256px 叠加核对。
- 不按每个姿势的透明包围盒重新居中或缩放；动作只能改变关节和身体受力，不能改变模型体量。

## 首轮交付

1. 可编辑模型文件及纹理/材质文件。
2. 正面、右侧、背面三张中性站立渲染图。
3. 面部特写渲染图。
4. 与 `canonical/running-highres.png` 同镜头的一张斜侧朝右渲染图。
5. 记录模型版本、相机参数、比例单位、纹理尺寸和导出命令。

不要在首轮直接生成完整跑步序列，也不要修改项目生产目录。先通过三视图和斜侧叠加确认模型身份，再制作动作和 PNG 帧。
