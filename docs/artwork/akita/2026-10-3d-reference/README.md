# Akita 3D 参考资料包

这是给 3D 建模/拟合工具使用的参考包，不是生产素材，也不会被运行时自动加载。

## 使用优先级

1. `canonical/idle-highres.png`：当前身份、脸部、正面体量和项圈的最高优先级参考。
2. `canonical/running-highres.png`：斜侧朝右的高分辨率身份和跑姿体量参考；当前低分辨率 Running 动画以仓库的 `codex_pet/assets/akita/frames/running/` 为准。
3. `canonical/ready-04-highres.png`：正面偏斜、下蹲和胸腹关系的辅助参考。
4. `canonical/production-*.png` 与 `production-frames/`：当前已经接入的 256×256 生产帧，用于核对轮廓、锚点、动作和状态表现；其中 Running 已同步为 `2026-10-grok-v2` 的20帧、834ms循环。
5. `generated/`：本轮新生成的正面、纯侧面、背面和面部候选，只用于补充深度、背面结构和面部细节；它们不能覆盖现有斜侧身份或直接作为生产帧。

`current-pet.json` 是当前实际播放清单的副本；`recording-evidence.json` 是本参考包保留的录屏证据元数据；Running 的来源和逐帧处理证据见 [`../2026-10-grok-v2/brief.md`](../2026-10-grok-v2/brief.md)。

## 固定身份

- 橙红色秋田犬幼犬，身体短而结实，头大、腿短、脸颊蓬松。
- 白色口鼻、脸颊、胸口和腿部；额头有纵向白色火焰纹。
- 大而直立的三角耳，耳内为浅粉米色。
- 棕色虹膜、黑色瞳孔和小高光；深棕黑色鼻子；张嘴露粉色舌头。
- 素蓝色哑光项圈，不能按状态改成其他颜色。
- 尾巴从背部卷起，橙白相间，尾尖蓬松。

## 模型拟合约束

- 先用 `canonical/idle-highres.png` 与 `canonical/running-highres.png` 锁定身份和斜侧镜头，再用新生成的正面/侧面/背面图估计不可见的深度。
- 正面、纯侧面、背面都应是中性站立，不要把奔跑、Ready 下蹲或歪头动作当作体型基准。
- 保持正交或弱透视相机、固定地面线、固定脚底和固定头部尺度；不要对每个姿势单独居中或缩放。
- 最终输出仍要能在 256×256 RGBA8、sRGB、64dp 宠物视图中读清轮廓。模型本身可以更高精度，但不能只在放大图上好看。

## 已知缺口

另一份评估中提到的“录屏提取 47 帧”原始图片不在当前仓库。仓库只有录屏证据和离线审查帧，不能把它们冒充为那 47 张原始录屏帧；如需逐帧拟合，请另外提供录屏或导出的 PNG。

当前包中的新视角是 AI 参考候选，尚未经过人工三视图一致性审查、3D 模型拟合或设备验收。不要直接覆盖 `codex_pet/assets/akita/`，应先导出独立的 `akita_3d` 候选包。
