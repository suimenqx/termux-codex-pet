# 秋田犬共享分层模型与骨骼动画 v1

## 任务、授权与契约

- 用户明确要求：所有秋田犬状态改用同一分层原画＋骨骼／网格动画，统一视觉尺寸。包含程序分层、蒙皮、变形、合成和逐帧导出；无需再次询问制作方式。
- 基线提交：`ff0a6a9`。范围为 Idle、Running、Needs input、Ready、Blocked；机器人不变。
- 唯一模型：右向三分之四视角，固定相机，橘红秋田犬、奶白圆脸胸腹、白额纹、蓝色项圈、卷尾。所有状态使用同一头部和躯干图层；头部仅刚性移动/旋转，禁止状态级缩放。
- 生产契约：256×256、8 bit RGBA、真实透明、64 dp ImageView。离线工具导出；运行时不求解骨骼、不引入绘图依赖；离线导出预乘像素包，运行时读取并缓存，复用一个原生显示缓冲区。
- 身份和初始构图参照：`docs/artwork/akita/2026-10-inbetweens/neutral-source.png`，1254×1254，SHA-256 `e7b93fcc65f3b1b2bc58676cfafafc8508de547e62f3edca9a99778ba482f4a7`。采用该图作为整个新模型的统一基准，而非独立匹配五张旧状态图。
- 原画生成使用内置 ImageGen；它只提供绑定所需的固定图层，后续每帧由同一模型确定性导出。模型 ID 未提供。部件源图实际尺寸为 2172×724，完整提示词为 `prompt-parts.txt`，参考输入为上述 neutral-source.png；工具返回的生成任务标识为 `01a0f674-5538-7e62-831b-242277eda156/exec-96246294-47bd-4c11-bb97-6607e86f335b.png`，未提供 seed。原图像素按 sRGB 工作目标解释，未进行额外色彩配置转换；裁切及 SHA-256 记录在 `model.json`。

## 分层与标定

头部、卷尾从固定参照分层保留；补画被其他部位遮住的躯干和完整前/后腿。远侧四肢使用同一前/后肢原画与固定的透视/明暗设置，不能随状态改变。绘制顺序为远侧腿、尾、躯干、近侧腿、项圈、头；关节根部藏入躯干，保留遮挡余量。

256单位设计坐标固定，原点 O=(128,236)。近侧足底 y234，远侧 y224，来自中性参照脚底及透视层次。头脸约占 x104–232、y30–148；中央额顶至下颌约102单位（人工标注±4），参照图中的耳和毛尖不作为尺度判据。构图和头身比例在绑定阶段一次确定，记录在 `model.json`；全状态沿用，动作极值用同一画布审查。

前/后肢使用固定长度骨骼与两段 IK，脚掌独立保持朝向；四肢使用重叠的刚性皮片，避免大屈曲时蒙皮翻折；局部网格只用于眼睑，全部取样采用预乘 alpha。支撑足随虚拟地面向后扫，回收足沿离地弧线向前，脚掌贴地与悬空必须由接触表区分。头部、尾根、胸、髋、四脚和遮挡信息随导出写入清单，重新建立审计，不沿用旧八帧标注。

绑定标记见 [bind-landmarks.png](bind-landmarks.png)，完整跑步联系表见 [running-contact.png](running-contact.png)，跨状态和极值见 [state-contact.png](state-contact.png)。部件图集不满足等格动作表要求，因此明确记录静态部件裁切框；没有把它伪装成动作表，也没有按动作帧的外接框缩放。源头上方的离散 alpha=1 杂点在固定头部蒙版中排除，耳朵轮廓完整。

## 动作设计

| 状态 | 动作及生命周期 | 计划时长与采样 |
| --- | --- | --- |
| Idle | 轻呼吸、一次眨眼、缓慢摆尾，循环 | 3.52秒；32姿势，呼吸120ms，眨眼局部40ms |
| Running | 交错四足疾驰、前后支撑与收腿腾空，循环 | 保留640ms周期；32姿势×20ms，设备上检查能否持续及时播放 |
| Needs input | 近前爪抬起、轻摆、保持、放回，循环 | 2.4秒；24姿势，手势段50–80ms，停留单独计时 |
| Ready | 站姿进入、下蹲、轻跃、落地缓冲一次，再休息 | 进入32姿势×40ms=1.28秒；随后复用Idle运动参数并保持绿色项圈 |
| Blocked | 轻歪头、停顿思考，最终姿势无限保持 | 16姿势×50ms=800ms，之后 until_state_change |

上述时间为本角色设计选择；640ms继承原有用户体验，其余曝光按动作段安排。增加帧不改变Running周期。所有状态首帧共享模型尺度与原点，提示色只作用于同一项圈蒙版。进入Needs input/Blocked等仍立即响应会话事件。

## 可复现入口

见[骨骼制作流程](../../../animation-rig.md#重建与导出)。本版本使用 `tools/requirements-art.txt` 固定 Pillow 12.3.0；源码以项目 Python 3.14.6 执行。运行时读取预制像素包并使用原生位图显示；libpng 供离线检查与缺少像素包时的兼容回退，不依赖 Pillow。

步态地面速度 240 设计单位/秒、固定透视、接触相位及可达性选择依据见[步态文档](../../../animation-gait.md)。头身没有 1.18 等状态级补偿。Ready 休息段直接采用 Idle 的同一组浮点姿势样本，避免独立累加时间导致的取样毛边差异。

## 设备时序与显示实现

测量日期为 2026-10-01，详情见 [validation.json](validation.json)。GUI 运行日志和带帧号的原始计时留在设备 `~/.cache/codex-pet/artwork-review/rig-v1/`。计时从 `OverlayUI.render` 进入到原生复制应答，不是屏幕实际呈现时间。

原先逐帧提交 PNG 在 20ms 曝光的持续试验中约 4 秒后断连，Android 退出原因未确定。改用共享位图后连接稳定，但首次逐像素预乘约 40ms，造成首轮跳帧。最终把该转换移入离线导出；标准 PNG 和预乘像素包由同一模型生成，像素相等关系由全帧测试锁定。ZIP 索引复用，运行时只解压、画不透明徽标并提交。
