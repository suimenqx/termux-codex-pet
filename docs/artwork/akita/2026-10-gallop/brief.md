# 秋田犬十六帧跑姿制作记录

日期：2026-10-01。基线：用户认可的 `d1b63b7`，本轮开始提交 `4faf813`。本轮仅替换 Running；Idle、Ready、Needs input、Blocked 的文件指纹保持原样。**后续用户评价：fail，动画生硬、奇怪。以下为原制作记录，不再代表视觉验收通过；复盘见 [diagnosis.md](diagnosis.md)。

## 制作目标和方法

保留橘白毛色、开心吐舌、蓝色项圈、短壮身体和卷尾。按[犬类研究](../../../research/canine-running-gait.md)的 transverse 方向安排后肢支撑、前肢交接、收腿腾空。最终分段稿选**远侧前后肢为领腿**，足序意图为近后 → 远后 → 近前 → 远前。领腿换侧是美术选择，不改变前后同侧领腿这一分类。

使用内置 `image_gen`。先尝试整张八帧、十六帧及带姿势控制图的生成；它们出现时序漂移、前脚支撑身份反转和构图差异，未接入。最终采用四帧一段的生成方式，再单独补画前肢回收过渡。失败草稿保存在本机 `~/.cache/codex-pet/artwork-review/gallop-rejected/`，不是生产来源。没有引入运行时骨架、网格变形、光流或帧混合。

## 角色尺度与构图

`identity-reference.png` 是批准原稿的 Running 首帧，兼作同视角身份、尺度参照；文件 SHA-256 在 `manifest.json`。其他状态沿用原始图片及其视角，没有重绘一套中性模型。

生成端虽然提供了固定尺度要求，实际构图仍偏大、偏高。因此导出执行一次**全部十六帧共用的参照配准**，而非把生成指令视为已经满足尺寸规范：

| 量 | 原稿 | 新稿 A0（按整格归一到 256 px） | 方法 |
| --- | --- | --- | --- |
| 近眼中心 | (182.5, 108) | (188, 86) | 对照暗色眼区的连通范围，人工确认对应关系 |
| 远眼中心 | (216.5, 109) | (227, 86) | 同上，约 1 px 标注误差 |
| 水平眼距 | 34 px | 39 px | 两中心横坐标相减 |
| 双眼中点 | (199.5, 108.5) | (207.5, 86) | 两中心平均 |

统一尺度 `s = 34 / 39`；统一偏移 `o = 原稿眼中点 − s × 新稿眼中点`。所有帧使用 `p_output = s × p_source + o`。这不是角色通用倍率，不逐帧测量后自动缩放，也不在运行时补偿。它只登记本批生成图到批准原稿的相同画布坐标。眼睛姿态和头部形状仍须视觉核对，眼距配准不能证明完整三维模型一致。

生产输出为 256×256、8 bit RGBA，PNG 直通道 alpha；导出直接从源格做预乘 alpha 双线性取样，避免重复降采样。画布固定，支撑足底按原稿三分之四视角投影解释；身体起伏被保留。工作色彩目标为同一橘白配色；工具没有提供模型名、seed 或可验证的色彩空间元数据，不声称获得了这些信息。

## 动作与时间

16 张不同的画稿，曝光均为 40 ms，总周期 `16 × 40 = 640 ms`，沿用旧版 `8 × 80 = 640 ms` 的步频。帧数与时刻是本角色的美术安排，不是实测犬只的通用相位比例。以下接触表表达绘制意图；PNG 的姿势与标记不能提供足底力测量。

| 帧 | 起始 ms | 支撑 / 动作意图 |
| --- | ---: | --- |
| 00 | 0 | 近后承重，远后接近落地；前脚屈起 |
| 01–02 | 40–80 | 后肢重叠支撑、接受重量，前爪开始前摆 |
| 03–04 | 120–160 | 近后离地、远后完成支撑，近前准备接触 |
| 05 | 200 | 近前承重，远前继续前伸，后腿回收 |
| 06–08 | 240–320 | 前肢交接与短暂重叠支撑，后肢屈曲向前收 |
| 09 | 360 | 近前抬起，远前最后支撑 |
| 10 | 400 | 远前开始离地，近前保持屈曲身份 |
| 11–12 | 440–480 | 收腿腾空，保持体积和俏皮表情 |
| 13–15 | 520–600 | 后脚依次下放，前脚屈起回收，接回 00 |

每帧实际四脚中心坐标见 `manifest.json`；明确不可见的远后脚使用 `null`，不以邻近脚替代。标记用于审查位置、遮挡及轨迹，不能从“动了足够多”推断步态正确。
